## Phase 4 – Vollständiges Beispielprojekt

Ein reales Musterprojekt wird vollständig dokumentiert:

```text
Idee
→ Nutzerbelege
→ PRD
→ Designsystem und Screens
→ Architektur
→ Repository
→ Supabase
→ KI-Funktion
→ Tests
→ Store-Release
→ Marketing
→ Updates und Betrieb
```

## Phase 5 – Ausgaben und Automatisierung

- [ ] versionierter PDF-Export
- [ ] DOCX-Export
- [ ] interaktiver Entscheidungsassistent
- [ ] Generator für projektspezifische Checklisten
- [ ] automatische Prüfung veralteter Quellen
- [ ] Changelog und Releasepakete

## Ziel von Version 1.0

Ein App-Projekt soll mit diesem Bereich von der ersten Idee bis zur Veröffentlichung und mindestens fünf Jahre Betrieb geführt werden können, ohne dass zentrale Produkt-, Design-, Technik-, Security-, Datenschutz-, Store- oder Wartungsschritte vergessen werden.
